ช่วยสร้าง Claude Artifact จากไฟล์ `ia-lab.html` ที่แนบมาให้หน่อย เป็นเว็บ "จัดหมวด Component" สำหรับให้ทีม UI ทำ card sort แล้วดู IA ที่ได้จากคำตอบของทีม

**สิ่งที่ต้องทำ**
1. ใช้ `ia-lab.html` เป็นต้นฉบับทุกอย่าง ห้ามแก้เนื้อหา ข้อความ รายการการ์ด หรือหน้าตา ถ้าไม่จำเป็นต้องแก้เพื่อให้ทำงานใน account นี้
2. ถ้ามี `REQUIREMENTS.md` แนบมาด้วย ให้อ่านและทำตาม ถ้าขัดกับ HTML ให้ยึดตาม requirement แล้วบอกฉันว่าต่างกันตรงไหน
3. ก่อน publish ให้โหลด skill `artifact-capabilities` แล้ว publish เป็น artifact ด้วย capabilities ชุดนี้เท่านั้น:

```json
{
  "db": { "rules": [
    { "path": "responses",        "read": "admin",    "write": "admin" },
    { "path": "responses/{self}", "read": "interact", "write": "interact" }
  ]},
  "user": { "scopes": ["profile"] },
  "downloads": true
}
```

   rules นี้ทำให้ผู้ตอบเขียนและอ่านได้เฉพาะคำตอบของตัวเอง ส่วนฉัน (เจ้าของ) อ่านได้ทั้งหมด
4. ตั้ง icon เป็น `cards`
5. หลัง publish ตรวจสิทธิ์ด้วย ArtifactData:
   - ใส่เอกสารทดสอบใน `responses` ในฐานะเจ้าของ
   - `list` ด้วย `as_level: "interact"` ต้องไม่เห็นเอกสารนั้น
   - ลบเอกสารทดสอบทิ้ง
   - บอกผลให้ฉันรู้
6. ข้อมูลใน `responses` ต้องว่างก่อนส่งลิงก์ให้ฉัน

**พฤติกรรมที่ต้องคงไว้**
- ตอนนี้เป็นรอบ 1 ทำ card sort อย่างเดียว (`TT_ENABLED = false` ซ่อน Tree test ไว้) ห้ามเปิดจนกว่าฉันจะสั่ง
- หน้าผลลัพธ์เปิดด้วยรหัส `0000`
- แท็บ "IA จากผลลัพธ์" มีแถบเลื่อน "IA หลังคนที่ n" และปุ่มส่งออก IA เป็น JSON
- ถ้ายังไม่มีคำตอบ ให้แสดงข้อมูลตัวอย่าง และห้ามเขียนข้อมูลตัวอย่างลงฐานข้อมูล

**ตอนส่งลิงก์ให้ฉัน ให้เตือนเรื่องนี้ด้วย**
- ต้องแชร์ลิงก์ให้ทีมเป็นสิทธิ์ **"Can interact"** ถ้าให้แค่ "Can view" ทีมจะส่งคำตอบไม่ได้
- รหัส `0000` เป็นแค่ประตูหน้าจอ ที่กันข้อมูลจริงคือ rules ในข้อ 3
